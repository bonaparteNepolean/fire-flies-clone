# Fireflies Clone

A meeting recording and transcript management application inspired by Fireflies.ai, built with Next.js and FastAPI.

## Features

- Upload meeting recordings and timestamped transcripts.
- Play recordings and synchronize playback with transcript timestamps.
- Edit speaker names and dialogue text.
- Delete individual transcript dialogues.
- Search and filter transcript entries.
- Manage meetings and action items.
- Meeting workspace with comments and bookmarks.

## Tech Stack

**Frontend:** Next.js, React, TypeScript, Tailwind CSS  
**Backend:** Python, FastAPI, SQLAlchemy  
**Database:** SQLite
